Love Engine Skill 是什么

它是 LoveEngineSkill 中第一个可以实际运行和验证的 Agent Skill，围绕公共表达建立一条完整的 Evidence 流程。

核心能力

  • 发布和验证 loveengine-witness release
  • 通过 Agent Network 派发观察与复核任务
  • 保存事件、Evidence 和 Signed Receipt（签名回执）
  • 在提案完整性门槛形成可检查结果

解决的问题

  • 记录公共表达发生的顺序和来源
  • 让多个 Agent 对同一份 Evidence 独立检查
  • 把观察、确认、Receipt 和 Review 串成完整流程
  • 把仍需处理的争议带到提案门槛之前

当前工作重点

  • 简化 release、Trust Policy（信任策略）和 Relay 的使用流程
  • 提高 Evidence、Review 和 Transcript（可验证记录）的可读性
  • 用本机和多节点实验验证异常恢复
  • 为后续公开试点准备清晰的参与方式

伙伴最常问的问题

答案只陈述当前代码和实验能够支持的范围。

Love Engine Skill 当前包含什么？

当前主线包含 release 验证、Agent 任务、事件与 Evidence、ACK、Signed Receipt（签名回执）、Review、提案完整性门槛和 Transcript（可验证记录）。

Agent 和 Voting Witness 如何分工？

Agent 执行观察与 Review，并签署 Signed Receipt（签名回执）；Voting Witness 在可选治理实验中使用外部 signer 显式批准投票。两条路径共享 Evidence，但保持各自权限。

把文本做哈希摘要，为什么还不能证明它是真的？

哈希摘要证明“当前取回的字节与当时保存的字节一致”，不能证明内容与现实相符。系统解决可追溯和可复核，不替代事实调查、来源判断或社会共识。

三个 Agent 的实验主要验证什么？

它验证成员身份、签名、法定数量、任务确认、Signed Receipt（签名回执）绑定和失败恢复等协议能力；后续公开试点再引入不同操作者和网络环境。

为什么需要额外的 Trust Policy（信任策略）？

Skill 说明“代码能做什么”，Trust Policy（信任策略）则独立固定“节点这次应该信任哪条链、哪个 Publisher、哪个版本、哪些哈希和任务签发方”。这个额外维度防止节点只根据连接邀请或任务自报信息建立信任。

下一轮验收重点是什么？

下一轮会用同一份 release 串联本机实验、远程实验、三节点 Signed Receipt（签名回执）、Transcript（可验证记录）和清理报告，使验收结果能够独立复跑。

直播场景如何进入后续路线？

直播场景将复用现有事件、Evidence、Review 和提案门槛，再通过直播设定合约增加时间和场次参数。

# 获取代码并准备依赖
git clone https://github.com/Wenbobobo/loveengine-witness-skill.git
cd loveengine-witness-skill
uv sync --frozen
uv run loveengine pilot contracts prepare

# 先用一条命令跑完核心流程，输出 Evidence、Signed Receipt（签名回执）和 Transcript（可验证记录）
uv run loveengine demo lan-pilot --stage core --events 12 --observers 10 --output .\core-output

# Terminal 1 · Publisher（发布方）：打包代码并生成 release
uv run loveengine package build --output .\release

# Terminal 2 · Operator（操作员）：启动本机 Pilot，并自动打开操作界面
uv run loveengine pilot quickstart --root .\pilot

# Terminal 3 · Observation Agent（观察 Agent）：使用 quickstart 生成的身份与 Trust Policy（信任策略）连接 Relay
uv run loveengine node connect --invite .\pilot\pilot-invite.json --trust-policy .\pilot\pilot-trust-policy.json --package .\pilot\release\loveengine-witness-0.7.0-invited-public-pilot.zip --profile .\pilot\profiles\node-1.json --rpc-url http://127.0.0.1:8545 --address ((Get-Content .\pilot\profiles\node-1.json | ConvertFrom-Json).profile.node) --cursor-db .\pilot\node-1.cursor.sqlite --expected-tasks 1 --idle-timeout-seconds 60 --output .\pilot\node-1-receipts.json

# Terminal 4 · Viewer（查看者）：打开只读页面
Start-Process "http://127.0.0.1:8780/demo/?lang=zh-CN"
