## Implementation layers

- M0: compatibility manifest, onboarding and tamper validation.
- M1: schemas, canonical hashes and CLI.
- M2: four contracts, EIP-712 local loop and LocalLoopTranscript.
- M3: SkillRegistry, Relay, signed tasks/receipts and NetworkTranscript.
- M4: implemented live evidence, three-process dispute review, ProposalGate, read-only dashboard and LiveReviewTranscript.
- M5 release candidate: deterministic Skill ZIP, authenticated LAN server,
  real three-Agent observation, persistent Anvil, explicit votes, recovery
  snapshots and package-to-PublicSink PilotTranscript.

The committed M4 audit fixture is `examples/transcripts/live-review.fixture.json`; it is regenerated by the live-evidence demo and verified by the CLI.
